# Приложуха — календарь, задачи и будильники в одном приложении (Android)

## Что внутри

**1. Календарь** — как Google Календарь: режимы «Месяц», «Неделя», «День», «Расписание».
На сетке видны события (цветные блоки), дедлайны задач (рамка с флажком ⚑, красная — если просрочено)
и будильники (⏰). Тап по пустому часу в режиме «День/Неделя» — новое событие на это время.
В месяце листается свайпом влево/вправо.

**2. Задачи** — лента, сгруппированная по срокам: Просрочено / Сегодня / Завтра / Ближайшие 7 дней / Позже / Без срока / Выполнено.
Быстрое добавление строкой сверху («Позвонить маме завтра» → срок на завтра). Приоритеты, повторы, заметки.
У повторяющейся задачи галочка переносит срок на следующий повтор.

**3. Сегодня** — карточка «Далее / Сейчас идёт», расписание дня с красной линией «сейчас», задачи на сегодня + просроченные с прогрессом.

**Любая запись** (событие, задача, будильник) может иметь:
- заметки (многострочный текст — показываются и на экране будильника);
- повтор: каждый день, по будням, по выбранным дням недели, ежемесячно, ежегодно;
- напоминание: в момент начала или за 5 мин … 1 день;
- переключатель **«На весь экран»** — тогда напоминание срабатывает как будильник.

**Полноэкранный будильник**: включает экран поверх блокировки, показывает время, название, заметки,
звонит мелодией будильника и вибрирует, пока не нажмёте «Выключить». Кнопки «Отложить на 5 / 10 / 30 мин»,
для задач — «Выполнено». Через 10 минут без реакции сам замолкает. Будильники переживают перезагрузку телефона.

## Как собрать и установить

1. Установите [Android Studio](https://developer.android.com/studio) (бесплатно).
2. Распакуйте архив, в Android Studio: **File → Open** → выберите папку `Prilozhuha`.
3. Дождитесь окончания синхронизации Gradle (первый раз скачивается несколько сотен МБ).
4. Вариант А — сразу на телефон: включите на телефоне «Режим разработчика» → «Отладка по USB»,
   подключите кабелем и нажмите зелёную кнопку ▶ **Run**.
   Вариант Б — APK-файл: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**,
   файл появится в `app/build/outputs/apk/debug/app-debug.apk` — перекиньте его на телефон и установите.

Требуется Android 8.0 и новее.

## После первого запуска

Сверху появится карточка с разрешениями — дайте их по очереди:
- **Уведомления** — обязательно;
- **Полноэкранные уведомления** (Android 14+) — обязательно, иначе будильник будет обычным баннером;
- **Поверх других приложений** — желательно: тогда будильник раскрывается на весь экран, даже когда вы сидите в телефоне
  (без этого на разблокированном телефоне он появится сверху баннером с кнопками, а на заблокированном — всё равно на весь экран).

Проверка: вкладка «Сегодня» → ⋮ → «Проверить полноэкранный будильник», заблокируйте экран и подождите 10 секунд.

**Xiaomi / Redmi / POCO, Huawei, Honor, Oppo, Realme, Vivo** агрессивно убивают фоновые приложения. Если будильник не сработал:
Настройки → Приложения → Приложуха → включите **Автозапуск**, а в «Контроле активности / Батарее» выберите **«Нет ограничений»**.

## Устройство кода

```
app/src/main/java/com/prilozhuha/app/
├── data/         Item (модель), Recurrence (повторы и расчёт срабатываний), Repo (хранение в JSON)
├── alarm/        AlarmScheduler (AlarmManager), AlarmReceiver/BootReceiver,
│                 AlarmService (звук + вибрация), AlarmActivity (полноэкранный экран), Notifications
└── ui/           CalendarScreen, Timeline, TasksScreen, TodayScreen, EditorDialog, PermissionBanner
```
Kotlin + Jetpack Compose (Material 3), без сторонних библиотек. Данные хранятся только на телефоне (`items.json`).
